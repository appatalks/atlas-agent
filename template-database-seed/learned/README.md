# Autonomous Learned Resolutions

ATSLA writes approved autonomous knowledge under stable `learned/<topic>.md` source paths inside the database snapshot. Do not add per-session transcripts here.

A candidate can auto-promote only when the interaction is resolved, its risk is low, its evidence is an exact transcript quote, its content passes poisoning and sensitive-data filters, and its confidence meets the application threshold. Positive customer feedback lowers the confidence threshold slightly; negative feedback blocks automatic promotion.

Repeated successful evidence can strengthen retrieval weight, but repetition never changes autonomous knowledge into seed or operator authority. Operators can review pending proposals, retire a bad topic, or replace the database from a known-good seed.
