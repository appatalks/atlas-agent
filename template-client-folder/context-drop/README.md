# Client Import Drop

Place reviewed client reference material here before selecting **Load context**. ATLAS imports `.md`, `.txt`, `.json`, `.csv`, `.yaml`, and `.yml` files into this client's private SQLite database.

Keep `CONTEXT-GUARDRAILS.md` current. It controls which client topics are safe to discuss and cannot be overridden by imported reference content. Files or folders named `restricted` and filenames containing `.restricted.` are retained for provenance but excluded from model recall.

Avoid credentials, unnecessary personal data, raw production exports, and regulated records. Prefer concise support extracts with clear ownership and provenance.
